# 渠道自动路由实施计划

1. 扩展数据库：逻辑模型统一售价、渠道模型成本价、任务逻辑模型、路由尝试记录，并迁移现有价格。
2. 重构模型目录与管理 API：普通用户只获得逻辑模型和售价；管理员分别维护售价和成本价。
3. 重构生图编排：按能力与成本产生候选，只用渠道首个 Key，失败逐渠道切换，保存尝试记录并保持单次扣退费。
4. 收口前端：选择器只显示逻辑模型，所有生图入口提交 `logicalModelId`，统一显示逻辑模型售价。
5. 更新管理界面与验收脚本，执行类型检查、构建和迁移校验。

风险控制：异步任务只在明确失败终态时跨渠道；状态不明的网络错误保持当前渠道；迁移保留旧字段并兼容旧 `channelModelId` 请求。
