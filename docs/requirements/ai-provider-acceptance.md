# AI 接入体系重构 · 验收文档（ai-provider）

> 对应功能方案 `docs/requirements/ai-provider.md`、技术方案 `docs/design/ai-provider-tech.md`、迁移手册 `docs/design/ai-provider-migration.md`。
> 本文档作为一次性交付（D11）的全量验收依据。级别定义：**S = 必须通过（阻断发布）**；A = 应当通过（次回合补齐）；B = 建议（记录跟踪）。

## 1. 验收范围与环境

### 1.1 模块划分

| 模块 | 范围 |
|---|---|
| M1 管理端配置 | 渠道管理、逻辑模型管理、渠道模型与定价管理 |
| M2 平台模型生图主流程 | 异步渠道（toapis）与同步渠道（openai_image / volcengine_image）两类链路 |
| M3 积分计费 | 预扣、402、失败退款、流水、统计口径 |
| M4 我的渠道 | 用户自建渠道、自加模型、可见性隔离、不计费 |
| M5 模型选择器与能力联动 | 渠道分组下拉、能力联动、价格展示 |
| M6 任务体系 | 内部任务号、轮询、转存、重试、下载命名、后台搜索 |
| M7 存量迁移 | 历史任务、共享/个人 Key 迁移正确性 |
| M8 全站回归 | 既有业务页面在新体系下的完整回归 |
| M9 安全 | Key 保护、SSRF 防护、越权访问 |

### 1.2 验收环境与账号矩阵

- 部署：测试环境全量部署（前端 + Express + 迁移已执行 + 种子完成）。
- 渠道矩阵：

| 渠道 | 协议 | 模式 | 用途 |
|---|---|---|---|
| ToAPIs（平台） | toapis | 异步 | 主回归链路 |
| 中转站B（平台） | openai_image | 同步 | 同步渠道链路（可用任意 OpenAI 兼容中转真实 Key） |
| 火山（平台，可选） | volcengine_image | 同步 | 协议正确性抽查 |
| userA 自建渠道 | 任选 | — | M4 |

- 账号矩阵：

| 账号 | 角色 | 用途 |
|---|---|---|
| admin | 管理员 | M1/M7/M9 配置与迁移验收、后台报表 |
| userA | 普通用户 | 主流程、我的渠道、积分计费 |
| userB | 普通用户 | 隔离验证（看不见 userA 的渠道/模型） |

### 1.3 前置条件

1. 迁移标记 `system_config.seed_ai_provider_v1 = done`（种子完成）。
2. admin 已配置 ToAPIs 平台渠道主 Key（迁移自原共享 Key 或新录）；已充值 userA 积分 ≥ 100。
3. userA 准备一个可用的 OpenAI 兼容渠道 base_url + Key（自建渠道用）。
4. 素材：3 张参考图、1 张服装正面图（成套生图回归用）。

## 11. 通过标准与回归结论

1. **S 级用例 100% 通过**方可发布；A 级允许 ≤2 项带条件通过（附修复计划）；B 级仅记录。
2. M8 回归中任一既有功能主流程失败即视为阻断（不论级别标注）。
3. 验收产出：用例执行记录表 + 缺陷清单（分级）+ 性能抽查（提交接口 P95、轮询端点耗时）。
