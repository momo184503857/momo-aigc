# 功能精简 · 2026-09-24

## 已确认范围

删除主题库、作品库、提示词工坊、提示词专家、成套提示词。

- 删除用户页面、导航、专属组件和 API 客户端，以及专属服务端路由。
- 删除配套后台页面：作品管理、提示词案例、提示词模块、成套生图资产（含独立后台与内嵌后台）。
- 删除任务详情与生图结果中的发布作品流程、提示词库中的工坊新建/编辑入口。
- 删除专家玩法的前端配置，保留功能提示词管理本身。
- 历史用户链接通过路由兜底回到自由生图；独立后台旧链接回到用户管理。

## 保留边界

模板图库、提示词库、自由生图、快速生图、AI 摄影、AI 买家秀、批量工具、AI 画布、生图记录及现行渠道/计费体系保持不变。

不执行数据库清表、迁移删除或图片清理。历史作品、主题、提示词、任务记录及上传文件保留，但已移除功能不再提供访问接口。数据库结构、历史兼容字段和初始化种子暂保留，不在本次进行破坏性数据迁移。

历史需求与设计文档仅作为背景档案；其中上述功能的启用说明由本文替代。

## 验证方式

- `npm run check`
- `npm run build`
- `npm run build:server`
- `node scripts/verify-feature-removal.mjs http://localhost:3000`
- 浏览器检查：精简导航、旧链接回退、提示词库读取和编辑弹窗、后台菜单、任务详情不再提供发布作品。

不提交实际付费生图任务，不执行生产部署。
