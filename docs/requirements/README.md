## 新建业务域

1. 在本目录新建 `<domain>.md`，包含：概述、角色与权限、数据模型、业务流程、默认值、业务规则与边界、验收标准、「需求变更记录」段。
2. 在上方清单加一行。
3. 在 [`../records/changelog.md`](../records/changelog.md) 追加一条带日期的变更记录。
