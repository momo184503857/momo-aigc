# 第一阶段交付与验收记录

## 当前状态

第一阶段视觉已于 2026-09-24 获用户认可；第二阶段 A/B 样板已实现，详见 [第二阶段验收](ui-phase-two-acceptance.md)。以下保留第一阶段原始验证边界。
管理员入口：`/admin/ui-components`、`admin.html#/ui-components`。
82 项登记示例（新增覆盖详见 ui-reference-coverage.md），覆盖现有基础组件族、公共组合与页面模式。
旧业务页面、旧组件库、旧全局主题未迁移；菜单新增入口，不改变业务接口。

## 已执行验证

- `npm run check`：前后端类型检查通过。
- `npm run build`：生产构建通过；仍存在产物超过 500kB 的提示。
- `npm run test:ui`：登记完整性、核心配色对比度、权限配置与主题作用域静态检查通过。
- `scripts/test-design-system-browser.cjs`：Chrome 无头模式，模拟 API。
  - 双入口、刷新、非管理员拦截。
  - 明暗主题，1366/1920/390px 宽度无页面级横向溢出。
  - 弹窗和下拉继承主题；Escape 关闭、触发按钮恢复焦点。
  - Toast 隔离到本主题，未重复发送到旧反馈宿主。
  - 图片翻页、真实文件选择器事件、公共组合、本地状态切换。
  - 主题不修改 body 变量；减少动效模式生效；无 pageerror。

浏览器测试运行方式：

```sh
# Vite 应已启动；需能解析 Playwright，或提供其模块绝对路径
PLAYWRIGHT_MODULE=/absolute/path/to/playwright npm run test:ui:browser
```

默认连接 localhost:5273，可用 UI_TEST_URL 改写；截图保存在系统临时目录 momo-ui-acceptance，可用 UI_TEST_OUTPUT 指定。

## 明确的未验证/待完善边界

- 浏览器验收使用模拟登录用户和 API，未验证真实服务登录，不触发真实生图、扣费或上传。
- 未执行旧业务页面迁移前后的完整截图基线比对；目前以旧组件/主题文件未改动、主题作用域和旧壳变量不变验证隔离。
- 核心色对通过计算，但尚未对所有变体进行完整 WCAG 审计；各基础控件适用状态需要用户在展厅中继续验收。
- 轻量柱形/折线图表示例已补充，更完整的任务/数据表格复杂场景尚待补充，不宣称覆盖所有业务状态。
- 静态检查只覆盖可可靠识别的字面颜色、深层覆盖、原生控件、旧库导入和部分任意视觉类；不能替代人工评审，也不能证明所有 token 已彻底收敛。
- 新基础组件暂以旧实现的隔离副本为迁移起点，部分尺寸仍来自 Tailwind 工具类；核心控件已增加集中 Token，但全量组件尺寸/间距 Token 化仍需进一步收敛。
- 第一阶段有意保留旧公共库；用户验收后再进行第二阶段，最终删除兼容副本。
