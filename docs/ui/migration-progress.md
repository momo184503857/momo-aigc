## 本批修改原则

- 认证页面使用公共字段、密码输入、认证面板，移除原页面视觉覆盖及认证容器的旧样式隔离。
- 表单统一走 submit，移除 Enter 的双重提交路径；请求中的提交防重和验证码发送状态在前端处理，不改变认证 API。
- 提示词库使用公共页面、分区、字段、分页、弹窗，标签／收藏操作可键盘访问；保留 API、校验、分页和数据处理逻辑。
- 提示词库按路由名称判定新主题，`/prompts` 与 `/assets/prompts` 行为一致。
- 截图验收发现全局通知缺少 vue-sonner 必需样式，已在公共 Sonner 入口加载，并补通知固定定位断言。
- 存量基线只删除本批已解决文件的旧记录；已迁移文件新增独立严格断言，不允许退回旧入口或旧 Token。
- 旧组件库、兼容主题、其他页面基线及原型暂不删除，待剩余依赖全部迁移和验收后再收口。
