# 第二阶段 A/B 样板交付与验收

日期：2026-09-24。状态：**已实现全局框架与自由生图样板，等待用户视觉验收。其余业务页面尚未批量迁移。**

## 本批结果

- 应用级公共主题与单个反馈宿主；两种后台入口不会重复渲染宿主。
- 创作模式栏、资源/提示词分组、后台三组导航；原 hash 网址保留；标签页缓存、侧栏收起状态保留。
- 用户端与管理端共享明暗及密度偏好；展厅明暗切换独立。深色工具类使用 CSS scope，不能穿透浅色展厅或旧页面兼容边界。
- 自由生图接入公共素材选择、参考图、参数操作、批次结果与图片动作组件；窄屏上下布局，图片每行最多四张，更多横向滚动。
- 共享任务面板、帮助、模板选择、详情/对比/发布弹窗接入公共基础组件；窄屏任务面板覆盖展示，不挤压工作区。
- 新增 4 个公共组合示例，展厅登记共 86 项。
- 规范基线从 1009 减少到 933，只移除 76 项已解决记录，没有接受新增违规。旧页面及底层绘图/富文本适配仍需后续批次处理。

## 真实服务与模拟边界

真实本地服务：使用已登录的管理员会话，确认自由生图模型目录、历史记录与 UI 展厅正常渲染。没有提交真实生图、扣费、重新导入或发布作品。截图中的历史图片来自本地服务。

自动化回归：所有 `/api/*` 均被测试上下文拦截。下载为测试图片，提交/重试/重新导入只命中模拟接口，不能据此宣称上游 AI 或真实计费已验收。未迁移业务页面、画布编辑全流程的验收留在 C 批次。
