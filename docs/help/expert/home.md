# 提示词专家

四种「拆图」玩法：给你一张图，产出可用的生图 Prompt 或成品图。

## 1. 原版拆解（18 项）

上传电商主图 → 自动提取主色/亮度/构图 → 按知识库选项填写 18 项拆解信息 →「智能推理补全」自动填空项 → 选择专家组装生成完整 Prompt，可复制、存入提示词库或一键应用到生成器。

- **四种组装策略**：提示词工程专家（结构化指令 · 稳定可控，默认）/ 图像提示词工程师（成像参数极致）/ 大模型提示词架构师（人衣景光拍五级分层）/ Master 框架（14 段全维度）。
- **智能推理补全**：优先按知识库关键词规则（新中式/法式/极简/成熟/甜美/宴会）匹配；规则未命中时，自动从提示词库的历史拆解中找相似主题兜底补全。
- **反馈闭环**：对推理结果标记「精准/需修正」——同主题被标「精准」的字段在后续推理中优先采用；被标「需修正」的主题，下次生成 Prompt 时自动附加历史修正指令。

## 2. 拆解融合

三向绑定：场景跟主图（最高权重参考）、脸跟模特人设、衣服跟服装参考图。上传主图 + 服装图即可一键融合出图。

## 3. 原图保真换脸换装

上传优质主图作为**绝对基底**：场景/光影/姿态/构图/色调 100% 保留，仅替换脸型/发型/服装——相当于让新模特在同一场拍摄、同一机位重拍一遍。可选传模特头像、发型参考、服装参考。

## 4. 空间叙事衍生

上传优质主图，填写衍生主题名与空间动线（5 个点位用 → 分隔），系统自动补全各点位描述。草稿可「存入我的主题库」或直接「生成套系」跳转成套生图继续。
