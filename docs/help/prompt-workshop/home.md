# 提示词工坊

提示词工坊帮你把一段完整的提示词拆成可复用的「模块」，需要时像拼积木一样组合出新的提示词，不用每次从零开始写。

## 使用场景

- 有一段效果很好的提示词，想沉淀下来反复使用
- 不同项目需要类似的风格描述，只想换其中一两个要素
- 想参考别人的成熟模块，快速拼装出专业提示词

## 核心概念

提示词工坊把提示词拆为两类积木：

| 概念 | 说明 | 示例 |
|------|------|------|
| 模块 | 一小段可复用的描述，按类型分组 | 主体：一位年轻女性模特 |
| 案例 | 多个模块拼装出的完整提示词 | 服装电商场景的完整组合 |

## 操作步骤

### 1. 浏览模块库

在提示词工坊首页可以看到按类型分组的模块卡片，常用类型包括：

- 主体（人物 / 商品）
- 服装与材质
- 场景与光线
- 镜头与构图
- 风格与画质

### 2. 拼装提示词

把需要的模块依次加入拼接区：

1. 从「主体」里选一个人物或商品模块
2. 按需叠加服装、场景、镜头模块
3. 在底部拼接预览中查看完整提示词
4. 标红部分表示该模块与已选内容有冲突，点击可替换

### 3. 应用到生图

拼装完成后点击【应用到生图】，提示词会自动填入生图表单，直接开始生成。

### 4. 保存为案例

拼好一段满意的作品后，点击【保存为案例】，方便下次直接整套调用。

## 注意事项

> 模块之间的冲突会以红色标出，生成前请先处理，否则可能得到预期外的画面。

> 社区模块由其他用户分享，效果因模型而异，建议先小图试生成。

## 常见问题

### 模块拼好后怎么应用到生图？

点击底部拼接预览区的【应用到生图】即可，提示词会自动带入生图表单。

### 可以修改别人的模块吗？

社区模块不能直接修改，但可以复制一份成为自己的模块后再编辑。

### 案例和模板图库的区别是什么？

案例只包含提示词模块组合；模板图库还包含参考图与完整生图配置。
