# 成套生图

上传一张服装图，自动匹配整套方案，一键生成「同一场景、5 个机位连续」的电商模特照。

## 使用流程（6 步向导）

1. **① 上传服装**：上传正面全身服装主图（必填）+ 细节图（袖口/印花/裙摆等，选填）。系统自动识别主色；勾选服装特征（风格/版型/面料/设计元素/配饰）帮助精准匹配。
2. **② 智能匹配**：系统推荐 3 个赛道 × 2 个主题共 6 个方案，点击卡片即应用；可换赛道 / 换主题 / 随机重匹配。
3. **③ 方案微调**：选择模特人设（DNA + 指纹库锁脸）、赛道、季节、空间主题。1 套主题 = 1 条空间动线 = 5 个点位「一步一景」。
4. **④ 服装细节**：按四层结构（版型轮廓 → 面料层次 → 结构细节 → 专属元素）+ 印花描述 + 配饰清单描述服装，防止 AI 丢配饰、简化版型。
5. **⑤ Prompt 预览**：左侧公共锁定部分（可单条开关/编辑），右侧 5 个点位差异，底部实时预览完整 Prompt。
6. **⑥ 生成**：确认模型/分辨率与积分预估后提交，系统串行生成 5 张（失败点位可单独重新生成）。

## 资产说明（通用 vs 我的）

- **通用**：管理员维护的主题/赛道/模特/锁定模板，所有用户开箱即用。
- **我的**：你私有创建的资产，仅自己可见；对通用资产不满意可先「复制为我的」再修改。

## 计费

5 张 = 5 个任务 = 5 × 单价积分，提交前会显示预估总额；任务失败自动退费。
